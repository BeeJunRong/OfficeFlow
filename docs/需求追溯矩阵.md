## v0.4.0 验收补充说明

- **FR-02 / FR-03 由 FR-01 派生**，不单独设 13 例样本；其验收以"派生正确 + 零编造 + 不发送"三条为准。
- **Q-02 口径变更**：原文为"首版不集成真实邮箱"。v0.4.0 引入可选的 `smtp` 协议，
  但默认 `draft_only` 且需要 `OFFICEFLOW_EMAIL_ENABLE_SEND=1` 才可能发送，**默认路径语义未变**。
  若验收要求严格回到原口径，保持该开关为 0 即可（见 guardrails §1.1）。
- **真实模型验收**：`scripts/check_acceptance_live.py` 用真实 LLM 跑 13 例，
  实测 12/13 通过、四条阈值全部达标（剩余 1 例为主题归一化差异，见下）。
- **已知差异（需团队决策）**：N3 的会议主题，标准答案为"产品评审"（规则引擎的截断式归一化），
  真实 LLM 输出"产品评审会议"（原文逐字短语，非编造）。
  两者均可辩护；若要统一，需决定改提示词做归一化、还是放宽该字段断言为"包含"语义。
